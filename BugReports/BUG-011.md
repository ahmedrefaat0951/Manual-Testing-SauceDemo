# BUG-011 — `problem_user`: Last Name Input Replaces First Name Instead of Populating Its Own Field

## Bug Information

| Field | Details |
|---|---|
| Bug ID | BUG-011 |

| Bug Type | Functional |
| Severity | **Critical** |
| Priority | **Critical** |
| Status | New |

## Environment

| Field | Details |
|---|---|
| Operating System | Windows 10 Home |
| Browser | Google Chrome 158.0.8127.36 |
| Application | SauceDemo |
| URL | https://www.saucedemo.com/ |

## Test Account

`problem_user`

## Preconditions

- User is logged in using the `problem_user` account.
- At least one product has been added to the Cart.
- User is on the **Checkout: Your Information** page.

## Steps to Reproduce

1. Enter `Ahmed` in the **First Name** field.
2. Click the **Last Name** field.
3. Enter `Refaat` one character at a time.
4. Observe the values displayed in both fields while typing.
5. Enter `1234` in the **ZIP/Postal Code** field.
6. Observe the values displayed in all three fields.

## Expected Result

- The **First Name** field retains `Ahmed`.
- The **Last Name** field accepts and retains `Refaat`.
- The **ZIP/Postal Code** field accepts and retains `1234`.
- Entering information in one field does not modify the values in other fields.

## Actual Result

- The **First Name** field initially accepted and displayed `Ahmed`.
- When entering `Refaat` in the **Last Name** field, each keystroke replaced the existing value in the **First Name** field.
- The **First Name** field displayed only the most recently entered character.
- The **Last Name** field remained empty throughout the process.
- The **ZIP/Postal Code** field accepted and displayed `1234`.

**Additional Observation — Chrome Autofill**

Using Chrome Autofill produced the following results:

| Field | Expected Value | Actual Value |
|---|---|---|
| First Name | Ahmed | Refaat |
| Last Name | Refaat | Empty |
| ZIP/Postal Code | 1234 | 1234 |

## User Impact

Users logged in with the `problem_user` account are unable to complete the checkout process because the Last Name field does not retain user input and instead overwrites the First Name field.

This prevents users from providing the required checkout information, effectively blocking them from completing purchases. The defect can result in abandoned transactions, lost sales, and damage to customer trust and the website's reputation.
