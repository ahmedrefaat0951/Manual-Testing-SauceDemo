## Environment

| Field | Details |

## Test Account

`standard_user`

## Preconditions

* User is logged in using the `standard_user` account.
* Cart contains no products.

## Steps to Reproduce

1. Open the **Cart** page.
2. Click the **Checkout** button.
3. On the **Checkout: Your Information** page, enter valid customer information:
   - First Name: `Ahmed`
   - Last Name: `Refaat`
   - ZIP/Postal Code: `12345`
4. Click the **Continue** button.
5. On the **Checkout: Overview** page, click the **Finish** button.
6. Observe the resulting page.

## Expected Result

* The user should not be able to complete checkout when the Cart contains no products.
* The checkout flow should prevent the order from being completed and should not display an order confirmation.

## Actual Result

* The user was able to proceed through checkout with an empty Cart.
* After clicking **Finish**, the user was redirected to the **Complete!** page.
* The message `Thank you for your order!` was displayed despite the Cart containing no products.
* A PDF order receipt was also generated for the empty order. The receipt contained no products and displayed Item total, Tax, and Total of `$0.00`.

## User Impact

The application allows users to complete checkout and receive an order confirmation even when no products have been added to the Cart. This may confuse users and reduce their confidence in the reliability of the checkout process. The resulting empty order receipt also gives the impression that an order was successfully processed despite containing no products.
