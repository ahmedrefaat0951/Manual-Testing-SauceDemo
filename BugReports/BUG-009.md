## Environment

| Field | Details |

| URL | https://www.saucedemo.com/ |

## Test Account

`problem_user`

## Preconditions

- User is logged in using the `problem_user` account.
- User is on the **Products** page.

## Steps to Reproduce

1. Locate the six products displayed on the **Products** page.
2. Click the title of each **product** individually.
3. Compare the **product title** clicked with the title of the resulting **Product Details** page.
4. Return to the **Products** page and repeat the process for the remaining products.

## Expected Result

- Clicking a product title should navigate to that product's corresponding **Product Details** page.
- The displayed product title and details should match the product selected on the **Products** page.

## Actual Result

Clicking each product title navigated to an incorrect **Product Details** page. In one case, the navigation resulted in an **ITEM NOT FOUND** page.

| Product title clicked | Resulting page |
|---|---|
| Sauce Labs Backpack | Sauce Labs Fleece Jacket |
| Sauce Labs Bike Light | Sauce Labs Bolt T-Shirt |
| Sauce Labs Bolt T-Shirt | Sauce Labs Onesie |
| Sauce Labs Fleece Jacket | ITEM NOT FOUND |
| Sauce Labs Onesie | Test.allTheThings() T-Shirt (Red) |
| Test.allTheThings() T-Shirt (Red) | Sauce Labs Backpack |

## User Impact

Users may be redirected to incorrect product pages when attempting to view product details. This can cause confusion, reduce trust in the website, and potentially lead to users making incorrect purchasing decisions. Although users can still add products directly from the **Products** page, the issue significantly affects the browsing experience.
