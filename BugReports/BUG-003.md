## Test Account

`standard_user`

## Preconditions

* User is logged in using the `standard_user` account.
* User has at least one product added to the Cart.
* User is on the **Checkout: Your Information** page.

## Steps to Reproduce

1. Leave the **First Name** field empty.
2. Enter `Refaat` in the **Last Name** field.
3. Enter `12345` in the **ZIP/Postal Code** field.
4. Click the **Continue** button.

## Expected Result

* The error message `Error: First Name is required` should be displayed.
* The **First Name** field should be visually identified as invalid.
* The **Last Name** and **ZIP/Postal Code** fields should remain in their normal visual state because they contain valid values.

## Actual Result

The error message `Error: First Name is required` was displayed, but the **First Name**, **Last Name**, and **ZIP/Postal Code** fields were all visually marked as invalid with a red X and red underline.

## User Impact

The visual validation feedback incorrectly suggests that the **Last Name** and **ZIP/Postal Code** fields contain invalid values, even though the displayed error message identifies only the **First Name** field as invalid. This may confuse users about which field requires correction.
